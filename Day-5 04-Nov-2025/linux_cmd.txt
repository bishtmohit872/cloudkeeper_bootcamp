#### cycle that vi follow ####
insert mode -> command mode -> normal mode

h : left
j : down
k : up
l : right
w : move to next word
b: move to previous word

x: delete single character
dd: remove current line
dw : remove word from current position of cursor

yy: copy current line
yw: copy current word

p : for pasting the current word / line

i : insertion before current cursor position
I : insertion started at starting of the line
a : insertion after current cursor position
A: insetion at ending of line

u: undo
ctrl +r : redo

w: save
q: quit

wq: save and quit

q! : forcefully quit
