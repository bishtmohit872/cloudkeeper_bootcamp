  Divergence happens when two branches start from the same commit but then each branch adds its own commits independently.

    After that point, both branches have different histories, so Git can’t fast-forward merge automatically.
    That’s called a diverged branch situation.

8)
  ## git init

  creates a new empty Git repository in your current folder.
  When starting a new project from scratch.
  .git folder present

  ## git clone

  Makes a copy of an existing repository (from GitHub or elsewhere).
  When you want to work on an existing project.
  .git folder present + all project files

9)
  ## git branch

  Used to create, list, or delete branches.
  When you want to make or manage branches in your repo.

  git branch does not switch to another branch, it just manages them.

  ## git checkout

  Used to switch between branches or restore files.
  When you want to move to another branch or check previous code.

10)
  ## git fetch

  Meaning: Downloads the latest commits, branches, and updates from the remote repo —
  but doesn’t change your local files.

  When you want to see what’s new on the remote before merging.

  ## git pull

  It fetches the new commits and then merges them into your current branch automatically.

  When you want to update your local branch with the latest remote changes.
